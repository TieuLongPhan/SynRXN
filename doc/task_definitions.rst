Task definitions
================

Each task specifies the information supplied to a method and the result it
should produce. The tables below describe the tasks in the main SynRXN
snapshot. Follow a task link to see its source tables, observation units,
and reuse terms.

Stored records count rows in released primary tables. Some tables contribute to
multiple tasks.

See :doc:`task_evaluation` for metrics and data splits, and
:doc:`data_records` for the fields in the canonical tables.
